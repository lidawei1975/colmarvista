3D Time-Domain FID Processing (Bruker & NUS)

Processing Raw 3D Time-Domain (FID) Data

COLMARvista 3D features a high-performance WebAssembly processing pipeline for raw 3D Bruker time-domain FID datasets directly inside the browser, with native Non-Uniform Sampling (NUS) reconstruction.

Supported Experiments & Required Files

  • Supported Experiments: 3D Bruker experiments from TopSpin console versions ≥ 3.0.
  • Required Parameter Files:
    • Direct dimension time-domain fid (or ser) and acquisition parameter file acqus.
    • Indirect dimension 1 acquisition file acqu2s ($F_1$).
    • Indirect dimension 2 acquisition file acqu3s ($F_3$).
    • NUS Experiments: Upload the NUS sampling schedule nuslist for 3D Non-Uniform Sampling experiments.
  • Drag and Drop: Drag and drop the entire 3D Bruker experiment folder directly into the upload drop area.

Dimension-Specific Processing Options

  • Direct Dimension ($F_2$):
    • Apodization string (e.g. sp off 0.5 end 0.896 pow 3.684 elb 0.0 c 0.5).
    • Zero filling factor (1, 2, 4, 8).
    • Phase correction P0 and P1 parameters.
    • Automatic Phase Correction: Check Automatic phase correction to run entropy/neural network phase optimization.
    • NUS FLATT Baseline Correction: Check Direct dimension FLATT baseline correction for NUS to eliminate baseline roll during NUS reconstruction.
    • Sub-Region Direct Extraction: Specify chemical shift bounds in Extract (ppm) from ... to ... to accelerate processing.
    • Keep Direct Imaginary Data: Check Keep direct dimension imaginary data for downstream manual phase adjustments.
  • Indirect Dimension 1 ($F_1$): Apodization string, zero filling factor (1, 2, 4, 8), and phase correction P0/P1.
  • Indirect Dimension 2 ($F_3$): Apodization string, zero filling factor (1, 2, 4, 8), and phase correction P0/P1.
  • Polynomial Baseline Orders: Configure time-domain polynomial orders TD Poly (f2 f1 f3) (e.g., 4 -1 -1) and frequency-domain polynomial orders Poly f2 (f2 f1 f3) (e.g., 4 1 1).

3D Non-Uniform Sampling (NUS) Automated Phase Estimation

For 3D Non-Uniform Sampling (NUS) experiments, automated phase correction functions on the direct dimension only:

  • Workflow & Mechanism: Similar to 2D NUS processing, to estimate direct-dimension phase correction parameters ($P_0 / P_1$) on 3D NUS data, the processing engine first executes a preliminary full direct Fourier Transform process (which contains NUS sampling artifacts) solely to calculate and optimize direct phase correction via ANN/entropy minimization. These estimated phase parameters are then applied to the raw time-domain data before executing full 3D NUS reconstruction. Indirect dimension phase parameters ($F_1, F_3$) cannot be automatically calculated on NUS data and must be set manually.
  • Show Spectrum with Artifact: Check Show spectrum with artifact to inspect the preliminary direct FT spectrum with NUS sampling artifacts used for phase estimation.

Process & Export Processed Spectrum

  • Click Upload and Process 3D FID to execute Fourier Transformation and NUS reconstruction.
  • Download Processed Spectrum: Click Download Processed .ft3 or Save as .ft3 to export the processed 3D dataset as an nmrPipe .ft3 binary file.

Uploading Pre-Processed 3D Spectra & Overlaying Theoretical Peaks

Uploading Pre-Processed 3D Spectra

If your 3D spectrum is already processed, you can upload it directly using one of two options:

Option 1: Series of 2D Planes

  • Select multiple 2D spectral files in nmrPipe (.ft2) or Sparky (.ucsf) format.
  • Files are automatically sorted alphabetically and stacked along the third dimension to construct the complete 3D volume.

Option 2: Single 3D Spectral File

  • Upload a single 3D spectral file in nmrPipe (.ft3), Sparky 3D (.ucsf), or raw binary format.
  • Drag and drop the single 3D file or containing folder into the drop zone.

Overlaying Theoretical 3D Peaks

  • Upload a theoretical peak list (.txt) in Overlay Theoretical 3D Peaks.
  • Click Load and Overlay Peaks to generate synthetic 3D Gaussian contours and display theoretical vs. experimental peak contours simultaneously in contrasting colors.

Standard Orthogonal 2D Planes & 1D Slices

Standard Orthogonal Views & 1D Slices

COLMARvista 3D presents synchronized orthogonal 2D slice planes along all three principal axes:

Synchronized 2D Slice Planes

  • XY Plane ($z$-Plane Slice): Display 2D cross-section at active $z$-depth. Drag slider or use < / > buttons to browse $z$-planes.
  • XZ Plane ($y$-Plane Slice): Display 2D cross-section at active $y$-position. Browse $y$-slices with slider controls.
  • ZY Plane ($x$-Plane Slice): Display 2D cross-section at active $x$-position. Browse $x$-slices with slider controls.

1D Traces Along Axis Centers

  • 1D Trace Along $Z$: Renders 1D spectral slice along $z$-axis at current $xy$ center.
  • 1D Trace Along $Y$: Renders 1D spectral slice along $y$-axis at current $xz$ center.
  • 1D Trace Along $X$: Renders 1D spectral slice along $x$-axis at current $yz$ center, complete with live $P_0$, $P_1$, and pivot point phase readouts.
  • Apply Phase: Adjust phase parameters on the 1D trace along $X$ and click Apply Phase to update the entire 3D volume phase in real-time.

Contour & Color Customization

  • Contour Threshold: Adjust Lowest level (x noise) (default 6.0x) and Scale factor (default 1.4x) and click Update Contours.
  • Custom Color Palettes: Customize independent color pickers for Positive Experimental, Negative Experimental, Positive Theoretical, Negative Theoretical, and Peak Marker symbols.

3D 2-in-1 Iterative Peak Picking & Line-Shape Fitting Workflow

3D Peak Picking & Fitting Workflow

2-in-1 Iterative Peak Picking & Line-Shape Fitting

COLMARvista 3D features a 2-in-1 iterative peak picking and line-shape fitting algorithm that simultaneously detects 3D peaks and optimizes their line-shape parameters.

  1. Overlapping Peak Cutoff: Set the overlapping peak cutoff parameter (range 0.2–0.6, default 0.4). Higher cutoff values tolerate distorted or broad peak shapes, while lower values prioritize discovering closely overlapping individual peaks.
  2. Run Peak Picking & Fitting: Click Peak Picking & Fitting to execute the 2-in-1 iterative workflow.
  3. Overlay Reconstructed Spectrum with Experimental Input: Upon completion, a synthetic 3D reconstructed spectrum is generated from the fitted peak parameters and rendered in the Reconstructed 3D canvas alongside the input Experimental 3D canvas (and overlaid on 2D orthogonal slices) for instant visual validation and quality control.

Floating 3D Peak Table Modal

  • Peak List Navigation: Displays all picked 3D peaks with chemical shifts ($F_1, F_2, F_3$) and intensities in a floating, resizable 3D Peaks List window.
  • Search Peaks: Type chemical shift values or assignment text into Search and press Enter to filter peak rows.
  • Jump to Peak: Click any peak row in the table to automatically center all 2D orthogonal slices and 3D WebGL canvases onto that peak.
  • Download Peaks: Click Download Peaks List to export picked peaks in tabular text format.

Floating 3D Background Log Console

  • Inspect real-time WebAssembly Fourier Transformation and 3D peak fitting progress in the floating 3D Processing Log modal.

2D Workspace Saving & Loading

Save and Load 2D Workspace

COLMARvista 2D allows you to save and restore your complete interactive analysis workspace to a local binary/JSON file.

  1. Save Session: Click the Save current session to a local file button to export your workspace state to a binary/JSON formatted .save or .colmar file.
  2. Load Session: Use the Load previous session file selector to restore a saved session file.
  3. Data Included in Save: Saves all frequency domain 2D spectra, contour levels, reconstructed spectra from peak fitting, picked/fitted peak lists, and pseudo-3D fitted peaks.
  4. FID Data Limitation: Unprocessed raw time-domain (FID) data is not stored in the session file. Saving is disabled while unprocessed FID files remain in the workspace.
  5. Contour Recalculation: Upon loading, COLMARvista automatically recalculates high-performance WebGL contour lines using saved contour level parameters.

Uploading, Interactive Viewing & Contour Controls for 2D Spectra

2D NMR Spectrum Viewer and Interactive Processor

COLMARvista 2D features a WebGL-accelerated interactive canvas for displaying, zooming, and overlaying multiple 2D NMR spectra.

Interactive Guided Tutorial

Click the green button at the top of the page at any time to launch an interactive guided UI walkthrough.

Uploading Frequency Domain Spectra

  • Supported Formats: Upload 2D NMR spectra in nmrPipe (.ft2), Sparky (.ucsf), or Topspin ASCII (.txt converted using totxt).
  • Drag and Drop: Drag and drop single spectral files or an entire folder containing 2D spectra into the Frequency domain spectra upload drop zone.

Contour Level Calculation & Customization

  • Separate Positive & Negative Contours: Positive (red/custom) and negative (blue/custom) contour levels are computed and rendered independently.
  • Automatic Noise Estimation (Logarithmic Scale): Noise levels are automatically estimated upon file upload. Default logarithmic contours start at $5.5 imes ext{noise}$ level, with subsequent levels increasing by a multiplier of $1.5$.
  • Linear Contours: Switch to a linear contour scale using the # of linear contours control for intuitive peak height representation.
  • Adjusting Contour Display: Customize display by adding lower contour levels (down button), adjust the lowest visible contour level slider in real-time, or select custom spectrum colors.

Interactive Plot Interactivity & Navigation

  • Zooming: Click and brush a rectangular area on the main 2D plot to zoom in. Use Reset all Zoom, Zoom Back (step back zoom stack), or Zoom out 120% buttons.
  • Reordering Spectra: Drag and drop loaded spectra in Your spectra list to reorder display depth layer rendering.
  • 1D Projections vs. Cross Section Slices: Toggle between Projection mode and Cross section mode. Hover the cursor over a peak location for 3 seconds (with Pause the cursor checked) or right-click to view synchronized 1D cross section slices along direct ($X$) and indirect ($Y$) dimensions.
  • Phase & Anchor Overlay: The 1D cross-section slice headers display real-time $P_0$, $P_1$, and anchor point phase parameters.

Magnifying Glass Tool

  • Enable/Disable: Check Enable in the Magnifying glass box at the top left of the plot.
  • Adjust Size & Magnification: Customize lens diameter percentage (10–40% of plot area) and magnification ratio (2.0x–30.0x) for ultra-close inspection without changing the main zoom level.

Plot Group View Synchronization

  • Set the Plot group number (range 1–10). Open 2D plots across different browser windows or tabs sharing the same group number automatically synchronize their ppm viewing region.

Baseline Correction (WebAssembly Accelerated)

  • Baseline Methods: COLMARvista 2D supports both Parametric and Polynomial baseline correction methods, implemented and accelerated directly in the browser via WebAssembly.
  • Algorithm Reference: Parametric baseline correction is based on the method described in:
    Baseline Correction for NMR Spectroscopic Metabolomics Data Analysis, Yuanxin Xi and David M. Rocke, BMC Bioinformatics (2008).
  • Order & Application: Select Parametric or Polynomial baseline method, choose polynomial order (0, 1, 2, 3, 4) if applicable, and click Apply Baseline.

High-Resolution & Vector Export for Publication

  • Resolution Scale Factor: Increase the Downloaded plot resolution factor from 1.0 up to 10.0 to download ultra-high-definition PNG contour plots matching publication standards.
  • Custom Font Size: Adjust plot label font size (12–72 pt) for optimal legibility.
  • Download Plot: Click Download plot to save PNG or vector SVG files.

DEEP Picker & Peak Fitting for 2D Spectra

2D Peak Picking Methods

  1. DEEP Picker: Click DEEP Picker to execute deep neural network peak detection using the current lowest contour level as the height threshold.
  2. Simple Picker: Click Simple Picker to identify mathematical local intensity maxima.
  3. Upload Peak List: Upload pre-existing peak lists in Sparky (.list) format.

Voigt / Gaussian Line-Shape Fitting

  1. Peak Profile: Select Voigt or Gaussian peak line shape profile.
  2. Perform Fitting: Click Peak Fitting to fit all picked peaks within the visible spectral window. A synthetic reconstructed spectrum is generated and overlaid.

Interactive Peak Editing

  • Brush to Remove: Check Brush to remove peaks to delete multiple peak markers inside a brushed region.
  • Drag and Drop: Check Drag and drop to move (or remove) peaks to reposition or delete individual peaks.
  • Click to Add: Check Click to add peaks to manually place new peak markers on the spectrum.

Automated Peak Label Placement & Repulsive Force Engine

  • Peak Labels & Assignments: Check Show peak label to render assignments (e.g. ASS) or peak parameters on all visible peaks.
  • Repulsive Layout Engine: Adjust label font size (12–72 pt), minimum/maximum label offset distance (e.g., 40–80 px), and Repulsive force weight (default 100). The layout engine dynamically repositions peak labels to prevent overlaps.

Interactive Peak Table & Search

  • Search Peaks: Search peak assignments or chemical shift coordinates in the peak table via Search in peaks.
  • Jump to Peak: Click any peak row in the table to automatically center and zoom the 2D plot onto that peak.

Processing Raw 2D & Pseudo-3D Time-Domain Data (Bruker & NUS)

Processing Raw 2D & Pseudo-3D Time-Domain Data

COLMARvista features an integrated WebAssembly processing pipeline for raw Bruker 2D and Pseudo-3D time-domain FID data directly in the web browser, with full support for Non-Uniform Sampling (NUS).

Supported Experiments & Required Files

  • Supported Experiments: 2D and Pseudo-3D experiments from Bruker TopSpin console versions ≥ 3.0. Indirect dimension mode supports Echo-antiecho or States-TPPI.
  • Required Files:
    • Direct dimension time-domain fid (or ser) and acquisition file acqus.
    • Indirect dimension acquisition file acqu2s.
    • Indirect dimension 2 acquisition file acqu3s (required for Pseudo-3D experiments).
    • NUS Experiments: Upload the NUS schedule file nuslist for Non-Uniform Sampling experiments.
  • Drag & Drop Folder: Drag and drop the entire Bruker experiment directory containing all files.

Processing Parameters

  • Direct & Indirect Apodization: Customizable nmrPipe syntax apodization strings (e.g., SP off 0.5 end 0.98 pow 2 elb 0 c 0.5).
  • Zero Filling Factor: Select zero filling factors (2, 4, 8) independently for direct ($X$) and indirect ($Y$) dimensions.
  • Sub-Region Direct Extraction: Specify chemical shift bounds in Extract direct dimension from (ppm) to (ppm) to process a targeted sub-region and accelerate transformation.
  • Water Suppression: Check Water suppression? to attenuate solvent signals.
  • Negative Imaginary Data: Check Negative imaginary data to invert indirect dimension phase and correct inverted/flipped spectra.

Non-Uniform Sampling (NUS) Processing & Phase Estimation

COLMARvista provides specialized processing controls for 2D and Pseudo-3D Non-Uniform Sampling (NUS) experiments:

  • Automated Phase Correction for NUS (Direct Dimension Only): For NUS datasets, automated phase correction functions on the direct dimension only.
    How it works: To estimate direct dimension phase parameters ($P_0 / P_1$) on NUS data, the processing engine first executes a preliminary full direct Fourier Transform process (which contains NUS sampling artifacts) to calculate and optimize direct phase correction via ANN/entropy minimization. These phase parameters are then applied to the raw time-domain data before performing full 2D NUS reconstruction (SMILE / iterative reconstruction). Indirect dimension phase parameters cannot be automatically calculated on NUS data and must be set manually.
  • FLATT Baseline Correction for NUS: Check Direct dimension FLATT baseline correction for NUS to eliminate baseline distortion during NUS reconstruction.
  • Process NUS as Normal: Check Process NUS spectrum as normal (No NUS recon) to bypass NUS reconstruction and perform rapid direct FT processing.

Pseudo-3D Processing Options

  • Process First Plane Only: Rapid processing on plane 1 for parameter tuning.
  • Process All Planes: Sequential batch processing across all planes in a Pseudo-3D dataset.

Process & Reprocess Workflow

  • Click Upload experimental files and process to start Fourier Transformation.
  • Reprocessing: Select a spectrum from the list and click Reprocess to reload parameters into the form, adjust phase/apodization settings, re-run processing, and click Quit reprocessing when done.

Automatic & Manual Phase Correction for 2D Spectra

2D Phase Correction Workflow

Automatic Phase Correction

Click Automatic PC to run entropy-minimization or neural network automated phase correction on the active 2D spectrum.

Interactive Manual Phase Correction

Manual phase correction requires imaginary data to be retained during initial 2D FID processing.

  1. Select Spectrum: Select the target spectrum in Your spectra list and click Reprocess.
  2. Display 1D Cross Section: Switch to Cross section mode. Hover the cursor over a strong peak for 3 seconds or right-click to display horizontal ($X$) and vertical ($Y$) 1D cross section slices.
  3. Adjust Zero-Order Phase (P0): Move the cursor onto either the direct ($X$) or indirect ($Y$) 1D cross-section plot. Hold Shift (1.0° coarse adjustment) or Ctrl (0.2° fine adjustment) and scroll the mouse wheel.
  4. Set Anchor Point & Adjust P1: Click on a peak in the cross-section plot to set an anchor point (indicated by an anchor line). Hold Shift or Ctrl and scroll the mouse wheel to adjust first-order phase ($P_1$). Right-click to unset the anchor point.
  5. Apply Phase Correction: Click Apply PC to apply phase correction to the full 2D spectrum. The exact $P_0$ and $P_1$ values are updated in the processing form and displayed for export into nmrPipe scripts.
2D / Pseudo-3D

Pseudo-3D Series Processing & 2D DOSY Diffusion Workflow

Pseudo-3D Data Processing & 2D DOSY Workflow

Processing Pre-processed Planes or Time-Domain Datasets

  1. Upload / Process Planes: Upload pre-processed 2D planes or process raw Pseudo-3D time-domain data (selecting Process all planes).
  2. Peak Picking & Fitting (Plane 1): Perform peak picking (DEEP Picker) and Voigt/Gaussian peak fitting on Plane 1 to establish a master peak list guess.
  3. Set Max Fitting Rounds: Set Max round of pseudo-3D fitting (1–1000, default 50).
  4. Run Pseudo-3D Fitting: Click Run Gaussian pseudo-3D fitting of all spectra or Run Voigt pseudo-3D fitting of all spectra to fit all planes sequentially.
  5. Transfer Assignments: Upload a Sparky peak list (.list) with assignment labels in Upload an peak file with assignment information to automatically transfer peak labels to pseudo-3D fitted peaks.
  6. Download Results: Download the complete fitted pseudo-3D peak table (.tab).

2D DOSY Diffusion Analysis

  1. Input Gradient Values: Enter space-separated gradient strength values into DOSY gradient values (e.g., 0.963 8.474 15.986 23.497 31.009 38.520).
  2. Set Gradient Weights & Rescale Factor: Enter space-separated gradient weight values (e.g. 1 0 0 1 1) and set the Rescale factor (0.1–10, default 1000.0).
  3. Run DOSY Fitting: Click Run DOSY fitting to calculate diffusion constants ($D$) for all pseudo-3D fitted peaks.
  4. Visualization & Decay Curves: Fitted diffusion constants automatically color-code peak markers and populate peak labels. Hover the cursor over any pseudo-3D peak to display the 2D exponential diffusion decay fitting plot in a pop-up window.

1D Workspace Saving & Loading

Save and Load 1D Workspace

COLMARvista 1D allows you to preserve and restore your exact analysis session, including frequency domain spectra and peak fitting results.

  1. Save Session: Click the Save current session to a local file button to export your workspace to a binary/JSON formatted .save or .colmar file. This file can be backed up or transferred to another computer.
  2. Load Session: Use the Load previous session file selector to select a previously saved .save or .colmar file to restore your workspace state.
  3. Data Included in Save: Saving preserves all frequency domain 1D spectra, reconstructed spectra from peak fitting, and all picked/fitted peak lists (including pseudo-2D fitted peaks).
  4. FID Data Limitation: Raw time-domain (FID) data is not saved in the session file. If un-processed FID data remains in your workspace without being converted to frequency domain spectra, saving is disabled until processing completes.

Uploading, Interactive Viewing & Plot Controls for 1D Spectra

1D NMR Spectrum Viewer and Interactive Processor

COLMARvista 1D provides a high-performance web-based interactive canvas for displaying single or multiple stacked 1D NMR spectra.

Interactive Guided Tutorial

Click the orange button at the top of the page at any time to start an interactive step-by-step UI walkthrough.

Uploading Frequency Domain Spectra

  • Supported Formats: Upload 1D NMR spectra in nmrPipe (.ft1), Sparky (.ucsf), or Topspin ASCII (.txt converted using totxt).
  • Drag and Drop: Select files via the file picker or drag and drop single files or an entire folder containing 1D spectra directly into the Frequency domain spectra area.

Interactive Plot Controls & Shortcuts

  • Frequency Zooming (X-Axis): Position the cursor over the plot area and use the mouse wheel to zoom in and out along the frequency (ppm / Hz) axis.
  • Intensity Zooming (Y-Axis): Position the cursor on the left side of the vertical Y-axis and use the mouse wheel to adjust signal intensity scale.
  • Panning: Click and drag anywhere on the plot to pan along the chemical shift axis.
  • Independent Spectrum Rescale & Referencing: Hold Alt while dragging to adjust the chemical shift reference of the active spectrum, or hold Alt while using the mouse wheel to rescale the active spectrum independently of other loaded spectra.
  • Reordering & Color Customization: Drag and drop spectra in the Your spectra list to change display stack order. Spectra listed later are rendered on top.

Plot Group View Synchronization

  • Multi-Window / Tab Sync: Set the Plot group (range 1–10). Open plots across different browser windows or tabs sharing the same group number automatically synchronize their chemical shift viewing range.

Export & Import Plot Bounds

  • Fill Plot Size and Zoom: Click Fill plot size and zoom to export the current pixel dimensions and zoom bounds string.
  • Apply Size and Zoom: Paste or edit a bounds string into the text box and click Apply plot size and zoom to restore an exact view.
  • Custom Font Size: Adjust label font size (range 8–72 pt) and click Apply.

Automatic Baseline Correction (WebAssembly Accelerated)

  • Parametric Baseline Method: COLMARvista 1D supports the Parametric baseline correction method, implemented and accelerated directly in the web browser via WebAssembly. Polynomial baseline methods are not used for 1D.
  • Algorithm Reference: Parametric baseline correction is based on the algorithm described in:
    Baseline Correction for NMR Spectroscopic Metabolomics Data Analysis, Yuanxin Xi and David M. Rocke, BMC Bioinformatics (2008).
  • Smooth Parameter: Set the baseline smoothing parameter (range 8–16, default 11).
  • Exclude Water Region: Check Exclude water suppression region to prevent solvent artifacts from distorting the calculated baseline.
  • Calculate & Apply: Click Calculate baseline to preview the baseline curve, then click Apply baseline correction to subtract it from the spectrum.

Vector SVG Export for Publication

  • Click the Download plot button to export the current 1D plot in resolution-independent vector SVG format suitable for publications.

Processing Raw 1D Time-Domain (FID) Data (Bruker, Magritek, Oxford)

Processing Raw 1D Time-Domain Data

COLMARvista 1D features a WebAssembly C++ processing engine to process raw 1D time-domain FID data directly inside the browser across high-field and benchtop NMR formats.

Supported Formats & Required Files

  • Supported Formats & Instruments:
    • Bruker: High-field TopSpin console version ≥ 3.0. Requires fid (or ser) and direct dimension acquisition parameter file acqus.
    • Magritek: Benchtop 1D NMR time-domain data formats.
    • Oxford Instruments: Benchtop 1D NMR time-domain data formats.
  • Drag & Drop Folder: Drag and drop the entire experiment folder containing the required files into the designated upload area.

FID Size Reduction Modes

  • Full: Process complete time-domain dataset without truncation.
  • Auto (Default): Automatically detects the signal decay end point to reduce noise accumulation before Fourier Transformation.
  • Auto & Confirm: Automated signal end detection with manual confirmation prompt.
  • Previous: Reuses previous reduction parameters for batch processing.

Apodization & Zero Filling

  • Apodization String: Supports standard nmrPipe apodization syntax (e.g., SP off 0.5 end 0.98 pow 2 elb 0 c 0.5).
  • Zero Filling Factor: Select zero filling factor (2, 4, or 8).

Phase Correction Algorithms

  • Peak Centric CNN: Convolutional neural network focusing on major peak region phases.
  • Full Spectrum ANN (Default): Artificial neural network trained on full spectrum phase optimization.
    Important Notice for Magritek Data: ANN-based automatic phase correction may not work well for Magritek benchtop NMR datasets. For Magritek data, manual phase correction or alternative phase algorithms are recommended.
  • Entropy Based: Automated minimum entropy optimization algorithm.
  • Manual: Retains raw phases for user manual phase adjustment.

Pseudo-2D Processing Options

  • Process First 1D Experiment Only: Rapid trial processing on the first trace.
  • Process All Pseudo-2D Traces: Sequential batch processing across all 1D traces in a pseudo-2D dataset.

Process & Reprocess Workflow

  • Click Upload experimental files and process to execute Fourier Transformation.
  • Reprocessing: Select a spectrum from the list and click Reprocess to reload parameters into the form, make adjustments, re-run, and click Quit reprocessing when done.

Automatic & Manual Phase Correction for 1D Spectra

1D Phase Correction Workflow

Automatic Phase Correction

Click the Run automatic phase correction button to trigger TensorFlow.js neural network automated phase optimization on the selected spectrum.

Interactive Manual Phase Correction

Manual phase correction requires imaginary data to be retained during initial FID processing.

  1. Select Spectrum: Choose a spectrum containing imaginary data from the spectra list.
  2. Zero-Order Phase (P0): With pivot unset, hold Shift (coarse adjustment) or Ctrl (fine adjustment) and scroll the mouse wheel to adjust P0.
  3. Set Pivot Point: Right-click on the spectrum at a major peak location to set a pivot anchor. A line indicator marks the pivot chemical shift.
  4. First-Order Phase (P1): With the pivot set, hold Shift (coarse) or Ctrl (fine) and scroll the mouse wheel to adjust P1. Right-click again to unset pivot.
  5. Live Readout: Watch the live parameter header showing Pivot status, Phase correction at left end, right end, and P1 value.
  6. Apply Phase Correction: Click Apply manual phase correction to permanently update spectral phases and frequency data.
Important Notes

Known Limitations

  • File Size Limit: COLMARvista has an inherent total file size limit of 16GB. It may fail if your spectral file is too large or if your pseudo-3D/3D experiments contain too many points.
  • Incomplete Experiments: 3D/Pseudo-3D time-domain data processing does not function if the experiment is incomplete (i.e., the actual number of traces along indirect dimensions is less than the planned number).
