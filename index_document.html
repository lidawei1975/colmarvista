2D NMR Spectra Instructions

2D

2D Workspace Saving & Loading

Save and Load

  1. You can save your current workspace to a binary file, which can then be copied to other computers, backed up, and later loaded again into COLMARvista, using the "Save current session to a local file" button.
  2. Use the "Load previous session" file selector to load a previously saved dataset.
  3. When saving, COLMARvista will save all frequency domain spectra, including reconstructed spectra from peak fitting, and all loaded, picked, and fitted peaks, including fitted pseudo-3D peaks. However, raw FID data will not be saved. Therefore, if unprocessed FID data remains in your workspace, saving is disabled until processing completes.
  4. When loading, COLMARvista will re-calculate contour data using the saved contour levels.
2D

Uploading & Interactive Viewing of 2D NMR Spectra

NMR Spectrum Viewer and Processor

This web-based tool allows you to view and process 2D NMR spectra.

Uploading Spectra

  • Upload one or more 2D NMR spectra in the following formats: nmrPipe (.ft2), Sparky (.ucsf), or Topspin ASCII (.txt converted using totxt). Use the 'Choose File' button to select your files.
  • Alternatively, drag and drop files directly into the dashed area labeled 'Frequency domain spectra'. Dropping a folder will process all supported files within the folder sequentially.

Contour Levels

  • Positive and negative contours are calculated and drawn separately.
  • Automatic Noise Estimation and Default Levels: The server automatically estimates the noise level for each uploaded spectrum. By default, contour levels are calculated on a logarithmic scale with:
    • The lowest contour level set to 5.5 times the estimated noise level.
    • Each subsequent level set to 1.5 times the previous level, up to the spectral maximum.
  • Linear vs. Logarithmic Contours: While the default is a logarithmic scale, you can switch to linear scale contours using the "# of linear contours" input and button. Linear contours intuitively represent relative peak heights.
  • Adjusting Contour Display: Customize display by adding lowest contour levels, using the lowest visible contour slider, or changing spectrum color.

Interacting with the Plot

  • Zooming: Brush an area in the main plot to zoom in. Use provided buttons to zoom out, return to full view, or reset all zoom levels.
  • Zooming (1D Projections/Cross Sections): Drag to pan and use mouse wheel to zoom on 1D projection plots. Viewing regions are synchronized.
  • Reordering Spectra: Drag and drop loaded spectra to reorder display depth.
  • Viewing Cross Sections: Select "Cross Section" or "Projection" mode. Hover cursor over location for 3 seconds or right-click to display 1D slices.

Magnifying Glass Tool

  • Enable/Disable: Toggle top-left magnifier button.
  • Adjust Magnification: Set magnification ratio (e.g. 4x, 10x) and lens diameter percentage.

Sync View Across Windows/Tabs

  • Plots sharing the same Plot Group number automatically synchronize their ppm range across browser tabs/windows.

Download Plot for Publication

  • Save the current 2D contour plot as PNG (up to 10x original resolution) or vector format for publication figures.
2D

Running Deep Picker & Peak Fitting for 2D

Running DEEP Picker and Peak Fitting

  1. Peak Picking Method: Select "DEEP Picker" (uses lowest contour level as cutoff) or "Simple Picker" (mathematical maxima). Alternatively, upload a pre-existing peak list (Sparky .list).
  2. Peak Editing: Enable peak editing checkbox above plot. Drag peaks to relocate/delete, brush area to delete multiple peaks, or click to add peaks.
  3. Peak Fitting: Choose peak profile (Voigt or Gaussian) and click "Peak Fitting" to fit peaks within the visible region.
  4. Reconstructed Spectrum: A synthetic reconstructed spectrum is generated and displayed.
  5. Visualization Customization: Adjust peak symbol size, line width, color-coding (by peak height or custom color), and peak label assignments.
2D

Processing Raw Bruker 2D Time-Domain (FID) Data

Processing Bruker 2D Data

  • Supported Experiments: 2D and pseudo-3D data (Bruker TopSpin ≥ 3.0). Supports Echo-antiecho or States-TPPI mode in indirect dimension.
  • Required Files: Direct dimension fid/ser and acqus, indirect acqu2s (and nuslist for NUS experiments).
  • Processing Parameters: Automatic phase correction along both dimensions by default. Apodization and zero filling parameters use nmrPipe syntax.
  • Process & Reprocess: Click "Upload experimental files and process". Select a spectrum to reprocess and modify parameters.
2D

Manual Phase Correction for 2D Spectra

Manual Phase Correction for 2D

  1. Enable Reprocessing: Select desired spectrum containing imaginary data.
  2. Display Cross Section: Activate 1D cross section slice by right-clicking or hovering.
  3. Adjust P0: Hold Shift (1.0 degree) or Ctrl (0.2 degree) and scroll mouse wheel over cross-section plot.
  4. Set Anchor & Adjust P1: Click on cross-section plot to set anchor point, then scroll wheel to adjust P1. Right-click to unset anchor.
  5. Apply Phase Correction: Click "Apply PC" to update 2D spectrum and export phase parameters for nmrPipe scripts.
2D / Pseudo-3D

Pseudo-3D Data Processing & DOSY Fitting Workflow

Pseudo-3D Data Processing & DOSY

Processing Pre-processed Planes

  1. Upload First Plane: Upload plane 1 processed spectrum.
  2. Peak Picking & Fitting (Plane 1): Perform peak picking and fitting on plane 1 to establish optimal master peak list.
  3. Upload Remaining Planes & Fit: Upload remaining planes, then click "Run Pseudo-3D Fitting".
  4. Optional Assignment Upload: Upload Sparky .list assignment file to transfer assignments to pseudo-3D fitted peaks.

2D DOSY Diffusion Analysis

  1. After pseudo-3D fitting, use the DOSY tool to calculate diffusion constants ($D$) for all peaks by entering gradient strengths and rescale constants.
  2. Fitted diffusion constants color-code peak markers and display quantitative $D$ values as peak labels.
  3. Hover cursor over pseudo-3D peaks to display 2D DOSY decay fitting curves in a pop-up window.

1D NMR Spectra Instructions

1D

1D Workspace Saving & Loading

Save and Load 1D Workspace

COLMARvista 1D allows you to preserve and restore your exact analysis session, including frequency domain spectra and peak fitting results.

  1. Save Session: Click the Save current session to a local file button to export your workspace to a binary/JSON formatted .save or .colmar file. This file can be backed up or transferred to another computer.
  2. Load Session: Use the Load previous session file selector to select a previously saved .save or .colmar file to restore your workspace state.
  3. Data Included in Save: Saving preserves all frequency domain 1D spectra, reconstructed spectra from peak fitting, and all picked/fitted peak lists (including pseudo-2D fitted peaks).
  4. FID Data Limitation: Raw time-domain (FID) data is not saved in the session file. If un-processed FID data remains in your workspace without being converted to frequency domain spectra, saving is disabled until processing completes.
1D

Uploading, Interactive Viewing & Plot Controls for 1D Spectra

1D NMR Spectrum Viewer and Interactive Processor

COLMARvista 1D provides a high-performance web-based interactive canvas for displaying single or multiple stacked 1D NMR spectra.

Interactive Guided Tutorial

Click the orange button at the top of the page at any time to start an interactive step-by-step UI walkthrough.

Uploading Frequency Domain Spectra

  • Supported Formats: Upload 1D NMR spectra in nmrPipe (.ft1), Sparky (.ucsf), or Topspin ASCII (.txt converted using totxt).
  • Drag and Drop: Select files via the file picker or drag and drop single files or an entire folder containing 1D spectra directly into the Frequency domain spectra area.

Interactive Plot Controls & Shortcuts

  • Frequency Zooming (X-Axis): Position the cursor over the plot area and use the mouse wheel to zoom in and out along the frequency (ppm / Hz) axis.
  • Intensity Zooming (Y-Axis): Position the cursor on the left side of the vertical Y-axis and use the mouse wheel to adjust signal intensity scale.
  • Panning: Click and drag anywhere on the plot to pan along the chemical shift axis.
  • Independent Spectrum Rescale & Referencing: Hold Alt while dragging to adjust the chemical shift reference of the active spectrum, or hold Alt while using the mouse wheel to rescale the active spectrum independently of other loaded spectra.
  • Reordering & Color Customization: Drag and drop spectra in the Your spectra list to change display stack order. Spectra listed later are rendered on top.

Plot Group View Synchronization

  • Multi-Window / Tab Sync: Set the Plot group (range 1–10). Open plots across different browser windows or tabs sharing the same group number automatically synchronize their chemical shift viewing range.

Export & Import Plot Bounds

  • Fill Plot Size and Zoom: Click Fill plot size and zoom to export the current pixel dimensions and zoom bounds string.
  • Apply Size and Zoom: Paste or edit a bounds string into the text box and click Apply plot size and zoom to restore an exact view.
  • Custom Font Size: Adjust label font size (range 8–72 pt) and click Apply.

Automatic Baseline Correction

  • Smooth Parameter: Set the polynomial/spline baseline smoothing parameter (range 8–16, default 11).
  • Exclude Water Region: Check Exclude water suppression region to prevent solvent artifacts from distorting the calculated baseline.
  • Calculate & Apply: Click Calculate baseline to preview the baseline curve, then click Apply baseline correction to subtract it from the spectrum.

Vector SVG Export for Publication

  • Click the Download plot button to export the current 1D plot in resolution-independent vector SVG format suitable for publications.

Running DEEP Picker, Line-Shape Fitting & Peak Editing (1D)

DEEP Picker & Peak Fitting for 1D Spectra

1D Peak Picking

  1. Cutoff Threshold: Choose the minimum peak height cutoff (as a multiple of estimated spectral noise) and click the DEEP Picker button to run deep neural network peak detection.

Voigt / Gaussian Line-Shape Fitting

  1. Profile Selection: Select either Voigt or Gaussian line shape fitting profile and click Peak Fitting. Fitting is performed on the current visible spectral window.
  2. Reconstructed Spectrum: Upon completion, a synthetic reconstructed spectrum is generated and overlaid on top of the experimental spectrum. The fitted peak list is associated with this new spectrum.

Interactive Peak Editing & Visual Customization

  • Drag-and-Drop Peak Editing: Check Drag and drop to move (or remove) peak. You can drag peak markers to fine-tune positions or drag markers off the spectrum area to delete them.
  • Visual Customization: Customize peak marker size (1–20), line thickness (1–10), toggle filled peak symbols, and choose custom peak colors using the color picker.
  • Individual Line Profiles: Zooming in reveals individual fitted peak component curves rendered as gray line shapes.

Interactive Peak Table & Search

  • Search Peaks: Filter picked peaks instantly by typing text or chemical shift values into the Search in peaks input box.
  • Jump to Peak: Click on any row in the peak table to automatically center and zoom the plot onto that peak.
  • Download Results: Download picked and fitted peak lists in tabular format for downstream analysis.

Processing Raw 1D Time-Domain (FID) Data (Bruker, Magritek, Oxford)

Processing Raw 1D Time-Domain Data

COLMARvista 1D features a WebAssembly C++ processing engine to process raw 1D time-domain FID data directly inside the browser across high-field and benchtop NMR formats.

Supported Formats & Required Files

  • Supported Formats & Instruments:
    • Bruker: High-field TopSpin console version ≥ 3.0. Requires fid (or ser) and direct dimension acquisition parameter file acqus.
    • Magritek: Benchtop 1D NMR time-domain data formats.
    • Oxford Instruments: Benchtop 1D NMR time-domain data formats.
  • Drag & Drop Folder: Drag and drop the entire experiment folder containing the required files into the designated upload area.

FID Size Reduction Modes

  • Full: Process complete time-domain dataset without truncation.
  • Auto (Default): Automatically detects the signal decay end point to reduce noise accumulation before Fourier Transformation.
  • Auto & Confirm: Automated signal end detection with manual confirmation prompt.
  • Previous: Reuses previous reduction parameters for batch processing.

Apodization & Zero Filling

  • Apodization String: Supports standard nmrPipe apodization syntax (e.g., SP off 0.5 end 0.98 pow 2 elb 0 c 0.5).
  • Zero Filling Factor: Select zero filling factor (2, 4, or 8).

Phase Correction Algorithms

  • Peak Centric CNN: Convolutional neural network focusing on major peak region phases.
  • Full Spectrum ANN (Default): Artificial neural network trained on full spectrum phase optimization.
    Important Notice for Magritek Data: ANN-based automatic phase correction may not work well for Magritek benchtop NMR datasets. For Magritek data, manual phase correction or alternative phase algorithms are recommended.
  • Entropy Based: Automated minimum entropy optimization algorithm.
  • Manual: Retains raw phases for user manual phase adjustment.

Pseudo-2D Processing Options

  • Process First 1D Experiment Only: Rapid trial processing on the first trace.
  • Process All Pseudo-2D Traces: Sequential batch processing across all 1D traces in a pseudo-2D dataset.

Process & Reprocess Workflow

  • Click Upload experimental files and process to execute Fourier Transformation.
  • Reprocessing: Select a spectrum from the list and click Reprocess to reload parameters into the form, make adjustments, re-run, and click Quit reprocessing when done.

Automatic & Manual Phase Correction for 1D Spectra

1D Phase Correction Workflow

Automatic Phase Correction

Click the Run automatic phase correction button to trigger TensorFlow.js neural network automated phase optimization on the selected spectrum.

Interactive Manual Phase Correction

Manual phase correction requires imaginary data to be retained during initial FID processing.

  1. Select Spectrum: Choose a spectrum containing imaginary data from the spectra list.
  2. Zero-Order Phase (P0): With pivot unset, hold Shift (coarse adjustment) or Ctrl (fine adjustment) and scroll the mouse wheel to adjust P0.
  3. Set Pivot Point: Right-click on the spectrum at a major peak location to set a pivot anchor. A line indicator marks the pivot chemical shift.
  4. First-Order Phase (P1): With the pivot set, hold Shift (coarse) or Ctrl (fine) and scroll the mouse wheel to adjust P1. Right-click again to unset pivot.
  5. Live Readout: Watch the live parameter header showing Pivot status, Phase correction at left end, right end, and P1 value.
  6. Apply Phase Correction: Click Apply manual phase correction to permanently update spectral phases and frequency data.
Important Notes

Known Limitations

  • File Size Limit: COLMARvista has an inherent total file size limit of 16GB. It may fail if your spectral file is too large or if your pseudo-3D experiments contain too many planes.
  • Incomplete Experiments: Pseudo-3D time-domain data processing does not function if the experiment is incomplete (i.e., the actual number of traces along the indirect dimension is less than the planned number).
