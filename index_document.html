2D NMR Spectra Instructions

2D

2D Workspace Saving & Loading

Save and Load

  1. You can save your current work space to a binary file, which can then be copied to other computers, backed up, and later loaded again into COLMARvista, using the "Save current session to a local file" button
  2. Use the "Load previous session" file selector to load a previously saved data.
  3. When saving, COLMARvista will save all frequency domain spectra, including reconstructed spectra from peak fitting, and all loaded, picked, and fitted peaks, including fitted pseudo-3D peaks. However, FID data will not be saved. Therefore, if you have FID in your workspace, you will NOT be able to save them.
  4. When loading, COLMARvista will re-calculate contour data using the saved contour levels.
2D

Uploading & Interactive Viewing of 2D NMR Spectra

NMR Spectrum Viewer and Processor

This web-based tool allows you to view and process 2D NMR spectra.

Uploading Spectra

  • Upload one or more 2D NMR spectra in the following formats: nmrPipe (.ft2), Sparky (.ucsf), or Topspin (.txt converted using totxt). Use the 'Choose File' button above to select your files.
  • Alternatively, drag and drop files directly into the dashed area labeled 'Frequency domain spectra'.
    • Dropping a folder will process all supported files within the folder sequentially.

Contour Levels

  • Positive and negative contours are calculated and drawn separately.
  • Automatic Noise Estimation and Default Levels: The server automatically estimates the noise level for each uploaded spectrum. By default, contour levels are calculated on a logarithmic scale with:
    • The lowest contour level set to 5.5 times the estimated noise level.
    • Each subsequent level set to 1.5 times the previous level, up to the spectral maximum.
  • Linear vs. Logarithmic Contours: While the default is a logarithmic scale, you can switch to linear scale contours using the "# of linear contours" input and the adjacent button. Linear contours can more intuitively represent relative peak heights but are less suitable for spectra with very high dynamic ranges.
  • Adjusting Contour Display: You can further customize the contour display by:
    • Adding a new lowest contour level (logarithmic scale) by clicking the down button.
    • Using the slider to adjust the lowest *visible* contour level without recalculating all levels.
    • Changing the color of each spectrum.

Interacting with the Plot

  • Zooming: Brush an area in the main plot to zoom in. Use the provided buttons to zoom out, return to the full view, or reset all zoom levels.
  • Zooming (1D Plots): On the two 1D plots, drag to pan and use the mouse wheel to zoom. The viewing regions of the 2D plot and the 1D plots are synchronized.
  • Reordering Spectra: When multiple spectra are loaded, drag and drop them to reorder their display on the plot. Spectra listed later will be drawn on top of earlier spectra.
  • Viewing Cross Sections: To view horizontal and vertical cross sections of a spectrum, select its "Cross Section" or "Projection" checkbox. When viewing cross sections, hover your mouse cursor over the desired location on the 2D plot for at least 3 seconds (with "Pause the cursor" checked) to activate the cross-section plot or right click on the plot (with "Right click" checked). Only one spectrum can be selected.

How to Use the Magnifying Glass Tool (on contour plot only)

  • Enable/Disable: Toggle the tool on or off (left-top of plot)
  • Adjust Magnification: Set ratio (e.g., 4, 10).
  • Set Size: Adjust the magnifier size as a percentage of the plot.
  • Use the Magnifier: Move the cursor over the plot to zoom in.
  • Disable: Turn it off when not needed.

Download plot for publication

  • The user can click the download button to save the current 2D contour plot as a PNG file. The downloaded image will match the on-screen dimensions in pixels.
  • COLMARvista also offers an option to increase the resolution of the downloaded file, up to 10 times the original size.
  • The user can also customize the plot label font size to achieve optimal visualization.
2D

Running Deep Picker & Peak Fitting for 2D

Running Deep Picker and Peak Fitting

  1. Peak Picking Method: For each experimental spectrum, choose a peak picking method: click "DEEP Picker" or "Simple Picker." DEEP Picker uses the current lowest contour level as the minimum peak height cutoff. The Simple Picker identifies mathematical maxima as peaks. Alternatively, you can upload a pre-existing peak list.

  2. Peak Editing: After running DEEP Picker, enable peak editing by checking the corresponding checkbox above the plot. You can then edit the picked peaks by:

    • Dragging peaks to the correct position or removing them by dragging them to an empty spectral region.
    • Removing multiple peaks within a selected area by brushing.
    • Adding new peaks by clicking on the plot.

  3. Peak Fitting: Select the desired peak profile (Voigt or Gaussian) and click the "Peak Fitting" button. Only the visible spectral region will be included in the fitting process.

  4. Reconstructed Spectrum: After fitting, a reconstructed spectrum is added to the plot. You can remove this reconstructed spectrum. The picked and fitted peak list is associated with this new spectrum.

  5. Rerunning Analysis: You can rerun peak picking (DEEP Picker or Simple Picker) and Peak Fitting with new parameters. Each new peak fitting run generates a new reconstructed spectrum.

  6. Downloading and Controlling Peak Visibility: You can download the picked and fitted peak list and control the visibility of the peaks using the provided buttons and checkboxes.

  7. Peak visualization is customizable, allowing users to adjust symbol size and line width. Peaks can be color-coded using various peak parameters (e.g., height) or a uniform color. Furthermore, labels displaying selected peak properties, such as assignments, can be added to all visible peaks.

Processing Raw Bruker 2D Time-Domain (FID) Data

Processing Bruker Data

  1. Files upload

    • Supported experiment: Currently, the tool supports 2D and pseudo-3D data. For Non-Uniform Sampling (NUS) experiments, only 2D data is supported. It also requires Bruker Topspin version ≥ 3.0 and it only supports Echo-antiecho or State-TPPI mode along indirect dimension.

    • Direct Dimension Files: Upload the FID file (typically named `fid` or `ser`) and the acquisition file (typically named `acqus`) for the direct dimension.

    • Indirect Dimension File: Upload the acquisition file for the indirect dimension (typically named `acqu2s`, or `acqu3s` for some pseudo-3D).

    • NUS Experiments: For NUS experiments, upload the NUS list file (typically named `nuslist`). Indirect phase correction must be provided in the processing part.

    • Drag and Drop: Alternatively, you can drag and drop the entire Bruker folder (containing the required files) into the designated area.

  2. Processing Parameters: The tool performs automatic phase correction along both dimensions by default, and the resulting phase correction values are populated in the input form. Other processing parameters (such as apodization and zero-filling) can be set as needed, using the same syntax as nmrPipe. Default values are suitable for most cases. Retaining imaginary data is recommended if manual phase correction is desired.

  3. Process Spectrum: Click "Upload experimental files and process" to begin processing the spectrum.

  4. Reprocessing: To reprocess a spectrum, select it in the spectra list and click the "Reprocess" button. The selected spectrum will be highlighted in both the spectral list and the processing input form. Make your changes in the processing form, and then click the "Reprocess" button again to apply the changes. Click the "Quit reprocessing" button in the spectral list when finished.

2D

Manual Phase Correction for 2D Spectra

Manual Phase Correction: To manually adjust phase correction after processing a spectrum:

  1. Enable Reprocessing: First, enable reprocessing for the desired spectrum. Note that imaginary data must be retained from the original processing for manual phase correction to work.
  2. Display Cross Section: Select "Cross section" (instead of "projection") to display the 1D cross section. Then, hover your mouse cursor over the desired location on the 2D plot for at least 3 seconds (with "Pause the cursor" checked) or right click on the plot (with "Right click" checked) to activate the cross-section plot.
  3. Adjust Zero-Order Phase (P0): Move your mouse cursor to either the direct or indirect dimension cross-section plot. Hold down the Shift key and use your mouse wheel to adjust P0 (zero-order phase correction). Each wheel event changes P0 by 1.0 degree. Use the Ctrl key for finer adjustments (0.2 degrees per event).
  4. Set Anchor Point: Click on the cross-section plot to set an anchor point. Right-click to unset the anchor point.
  5. Adjust First-Order Phase (P1): With an anchor point set, use the mouse wheel to adjust P1 (first-order phase correction). You can zoom and pan the plot to focus on other parts of the cross section. You can also switch to another cross section by relocating your mouse cursor on the 2D plot.
  6. Apply Phase Correction: Once you are satisfied with the phase correction, click "Apply PC" to apply the changes to the 2D spectrum. The processing parameters in the form will be updated accordingly. Optionally, you can reprocess with the new phase correction values to correct any potential rounding errors.

Manual Phase Correction: To manually adjust phase correction a uploaded nmrPipe .ft2 file

  1. Imaginary part of data must be retained in the ft2 file for this tool to work.
  2. Display cross section and run manual phase correction like above.
  3. Apply Phase Correction: Once you are satisfied with the phase correction, click "Apply PC" to apply the changes to the 2D spectrum. The optimal phase correction values will be printed just after the "Apply PC" button, which can be copied to your own nmrPipe processing script.
  4. Alternatively, you can also click the "Automatic PC" button to run an automatic phase correction.
2D / Pseudo-3D

Pseudo-3D Data Processing & DOSY Fitting Workflow

Pseudo-3D Data Processing (Pre-processed Spectra): To process pseudo-3D data from pre-processed spectra:

  • Upload First Plane: Upload the first plane of your pseudo-3D experiment. This should be a processed spectrum in a supported format.
  • Peak Picking and Fitting (Plane 1): Perform peak picking on the first plane using either Deep Picker or by uploading a pre-existing peak list. Optionally, edit the picked peaks and then perform peak fitting to obtain an optimal peak list for this plane.
  • Upload Remaining Planes: Upload the remaining processed planes of your pseudo-3D experiment. Ensure that the fitted peaks from plane 1 are visible on the plot.
  • Run Pseudo-3D Fitting: Run the pseudo-3D fitting process, selecting the appropriate line shape for your data.
  • Optional Assignment Upload: Optionally, upload an assignment file (Sparky .list). These assignments will be transferred to the fitted peaks from the pseudo-3D fitting.
  • Download Results: Download the results from the pseudo-3D fitting.

Pseudo-3D Data Processing (Bruker FID Data): To process pseudo-3D data directly from Bruker time-domain (FID) data:

  • Process All Planes: Upload the Bruker time-domain data. Initially, select the "Process the first plane only" option and click "Process." Make any necessary adjustments to the processing parameters. Then, select the "Process all planes" option and click "Process" again. This will process all planes sequentially and add them to the spectral list.
  • Peak Picking and Fitting (All Planes): Follow the steps outlined above for pre-processed spectra (Peak Picking and Fitting (Plane 1), Upload Remaining Planes, Run Pseudo-3D Fitting, Optional Assignment Upload, and Download Results) to complete the pseudo-3D analysis.

2D DOSY is a pseudo-3D NMR experiment that separates molecules based on their diffusion.

  1. Following standard pseudo-3D processing, users can employ the DOSY tool to fit diffusion constants for all identified peaks. This requires providing gradient strengths and a rescale constant to accurately determine the diffusion coefficients.
  2. The fitted diffusion constants can then be used to color-code the peaks in the main plot, visually representing diffusion differences. Additionally, these diffusion constant values can be added as labels to each peak, providing direct quantitative information about molecular size and behavior.
  3. If you want to check the fitting quality, hover your mouse over pseudo-3D peaks to display DOSY fitting details as a 2D plot.

Manual Phase Correction for 1D Spectra

Manual Phase Correction: Use the following steps to manually adjust phase correction after processing a 1D spectrum:

Please run this manual correction before any reference correction.

  1. Select a spectrum from the spectra list. The spectrum must contain imaginary data.
  2. Hold Shift (for coarse adjustment) or Ctrl (for fine adjustment), then use the mouse wheel to adjust the P0 phase.
  3. Right-click on the spectrum to set or unset an anchor point at the current cursor chemical shift.
  4. When an anchor is set, hold Shift (coarse) or Ctrl (fine) and use the mouse wheel to adjust the P1 phase.
  5. You can re-adjust the P0 phase after unsetting the anchor.
  6. Manual phase correction is applied when you either select another spectrum from the list or click the Apply button.
Important Notes

Known Limitations

  • File Size Limit: COLMARvista has an inherent total file size limit of 4GB. It may fail if your spectral file is too large or if your pseudo-3D experiments contain too many planes.
  • Incomplete Experiments: Pseudo-3D time-domain data processing does not function if the experiment is incomplete (i.e., the actual number of traces along the indirect dimension is less than the planned number).
  • NUS Limits: Non-Uniform Sampling (NUS) reconstruction is limited to 2D experiments only at this time.
