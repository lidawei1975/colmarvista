2D & Pseudo-3D NMR Documentation

Complete user guide for 2D NMR spectrum viewing, 3D surface rendering of 2D spectra, WebAssembly FID processing, Non-Uniform Sampling (NUS), Pseudo-3D series fitting, 2D DOSY diffusion analysis, CEST conformational exchange & ChemEx simulation/fitting, and automated assignment transfer.

2D

2D Workspace Saving & Loading

Save and Load 2D Workspace

COLMARvista 2D allows you to save and restore your complete interactive analysis workspace to a local binary/JSON file.

  1. Save Session: Click the Save current session to a local file button to export your workspace state to a binary/JSON formatted .save or .colmar file.
  2. Load Session: Use the Load previous session file selector to restore a saved session file.
  3. Data Included in Save: Saves all frequency domain 2D spectra, contour levels, reconstructed spectra from peak fitting, picked/fitted peak lists, and pseudo-3D fitted peaks.
  4. FID Data Limitation: Unprocessed raw time-domain (FID) data is not stored in the session file. Saving is disabled while unprocessed FID files remain in the workspace.
  5. Contour Recalculation: Upon loading, COLMARvista automatically recalculates high-performance WebGL contour lines using saved contour level parameters.

Uploading, Interactive Viewing & Contour Controls for 2D Spectra

2D NMR Spectrum Viewer and Interactive Processor

COLMARvista 2D features a WebGL-accelerated interactive canvas for displaying, zooming, and overlaying multiple 2D NMR spectra.

Interactive Guided Tutorial

Click the green button at the top of the page at any time to launch an interactive guided UI walkthrough.

Uploading Frequency Domain Spectra

  • Supported Formats: Upload 2D NMR spectra in nmrPipe (.ft2), Sparky (.ucsf), or Topspin ASCII (.txt converted using totxt).
  • Drag and Drop: Drag and drop single spectral files or an entire folder containing 2D spectra into the Frequency domain spectra upload drop zone.

Contour Level Calculation & Customization

  • Separate Positive & Negative Contours: Positive (red/custom) and negative (blue/custom) contour levels are computed and rendered independently.
  • Automatic Noise Estimation (Logarithmic Scale): Noise levels are automatically estimated upon file upload. Default logarithmic contours start at $5.5 imes ext{noise}$ level, with subsequent levels increasing by a multiplier of $1.5$.
  • Linear Contours: Switch to a linear contour scale using the # of linear contours control for intuitive peak height representation.
  • Adjusting Contour Display: Customize display by adding lower contour levels (down button), adjust the lowest visible contour level slider in real-time, or select custom spectrum colors.

Interactive Plot Interactivity & Navigation

  • Zooming: Click and brush a rectangular area on the main 2D plot to zoom in. Use Reset all Zoom, Zoom Back (step back zoom stack), or Zoom out 120% buttons.
  • Reordering Spectra: Drag and drop loaded spectra in Your spectra list to reorder display depth layer rendering.
  • 1D Projections vs. Cross Section Slices: Toggle between Projection mode and Cross section mode. Hover the cursor over a peak location for 3 seconds (with Pause the cursor checked) or right-click to view synchronized 1D cross section slices along direct ($X$) and indirect ($Y$) dimensions.
  • Phase & Anchor Overlay: The 1D cross-section slice headers display real-time $P_0$, $P_1$, and anchor point phase parameters.

Magnifying Glass Tool

  • Enable/Disable: Check Enable in the Magnifying glass box at the top left of the plot.
  • Adjust Size & Magnification: Customize lens diameter percentage (10–40% of plot area) and magnification ratio (2.0x–30.0x) for ultra-close inspection without changing the main zoom level.

Plot Group View Synchronization

  • Set the Plot group number (range 1–10). Open 2D plots across different browser windows or tabs sharing the same group number automatically synchronize their ppm viewing region.

Baseline Correction (WebAssembly Accelerated)

  • Baseline Methods: COLMARvista 2D supports both Parametric and Polynomial baseline correction methods, implemented and accelerated directly in the browser via WebAssembly.
  • Algorithm Reference: Parametric baseline correction is based on the method described in:
    Baseline Correction for NMR Spectroscopic Metabolomics Data Analysis, Yuanxin Xi and David M. Rocke, BMC Bioinformatics (2008).
  • Order & Application: Select Parametric or Polynomial baseline method, choose polynomial order (0, 1, 2, 3, 4) if applicable, and click Apply Baseline.

High-Resolution & Vector Export for Publication

  • Resolution Scale Factor: Increase the Downloaded plot resolution factor from 1.0 up to 10.0 to download ultra-high-definition PNG contour plots matching publication standards.
  • Custom Font Size: Adjust plot label font size (12–72 pt) for optimal legibility.
  • Download Plot: Click Download plot to save PNG or vector SVG files.

Spectrum Ratio Heatmap (WebGL Overlay)

The Spectrum Ratio Heatmap tool allows real-time comparative visualization between two 2D spectra (A and B) directly under the contour plot via WebGL acceleration.

  • Input & Selection: Designate the 1-based spectrum indices for numerator spectrum A and denominator spectrum B in the input fields located on the plot control bar (default is 2 over 1, i.e., 2 / 1).
  • Positive Data & Contour Threshold Filtering: Only positive data points from both spectra are considered. The ratio is evaluated and rendered only where both spectra exceed their respective lowest displayed positive contour levels (A ≥ contourA and B ≥ contourB). Negative data points or points below the positive contour threshold are discarded.
  • Per-Fragment Smooth Interpolation: Raw intensity values of both spectra are uploaded to WebGL as 32-bit floating-point textures and bilinearly interpolated in the fragment shader prior to ratio evaluation, ensuring smooth color transitions without block artifacts when zooming in.
  • True Min/Max Normalized Ratio Scale: The ratio is computed directly as r = A / B and dynamically normalized across the true data range:
    s = (r − rmin) / (rmax − rmin) ∈ [0, 1]
    where rmin and rmax are the actual minimum and maximum ratios among all valid points.
  • Selectable Colormaps & Interactive Colorbar: Choose from multiple built-in color schemes via the dropdown menu (Red/Blue, Coolwarm, Viridis, Plasma, Jet, Grayscale). An interactive horizontal colorbar displays the gradient, and its two ends are automatically labeled with the true minimum ratio (rmin) on the left and true maximum ratio (rmax) on the right.
  • Layering & Interactivity: The heatmap is rendered beneath the contour lines, stays fully synchronized across pan and zoom operations, displays within the magnifying glass tool, and is preserved when using Download plot. Click Clear ratio to remove the overlay and reset the colorbar labels.

3D Surface & Terrace Visualization for 2D Spectra

3D Surface & Terrace Visualization for 2D Spectra

In addition to 2D flat contour viewing, COLMARvista provides a dedicated 3D View for 2D Spectra mode (index_2d_3dview.html) that projects a 2D NMR spectrum as a 3D elevation landscape using WebGL.

Key Features of 3D View for 2D Spectra

  • 3D Surface vs. Terrace Rendering:
    • 3D Surface Mode: Renders a smooth 3D elevation terrain where peak intensities map directly to vertical $Z$-axis peak heights.
    • 3D Terrace Mode: Renders stepped contour terraces for clear visual demarcation of intensity levels.
  • Interactive 3D Viewport Controls:
    • Tilt & Rotation: Adjust Tilt ($-200^\circ$ to $200^\circ$) and Rotation ($0^\circ$ to $360^\circ$) sliders to view the 2D spectrum from any perspective angle.
    • $Z$ Scale & $Y$ Scale: Scale vertical signal peak height ($Z$-scale) and spectrum aspect ratio ($Y$-scale) dynamically.
    • Lighting Angle & Orientation: Customize Light Angle and Light Orientation for optimal 3D shading and shadow contrast.
  • Custom Surface & Contour Styling: Customize independent color pickers for Surface color and Contour color.
  • Contour Modes: Choose between Logarithmic-linear, Logarithmic, or Linear contour spacing.
  • Download 3D Figure: Click Download figure to capture and save the interactive 3D surface model as an image.

Running DEEP Picker, Peak Fitting & Label Layout for 2D

DEEP Picker & Peak Fitting for 2D Spectra

2D Peak Picking Methods

  1. DEEP Picker: Click DEEP Picker to execute deep neural network peak detection using the current lowest contour level as the height threshold.
  2. Simple Picker: Click Simple Picker to identify mathematical local intensity maxima.
  3. Upload Peak List: Upload pre-existing peak lists in Sparky (.list) format.

Voigt / Gaussian Line-Shape Fitting

  1. Peak Profile: Select Voigt or Gaussian peak line shape profile.
  2. Perform Fitting: Click Peak Fitting to fit all picked peaks within the visible spectral window. A synthetic reconstructed spectrum is generated and overlaid.

Interactive Peak Editing

  • Brush to Remove: Check Brush to remove peaks to delete multiple peak markers inside a brushed region.
  • Drag and Drop: Check Drag and drop to move (or remove) peaks to reposition or delete individual peaks.
  • Click to Add: Check Click to add peaks to manually place new peak markers on the spectrum.

Automated Peak Label Placement & Repulsive Force Engine

  • Peak Labels & Assignments: Check Show peak label to render assignments (e.g. ASS) or peak parameters on all visible peaks.
  • Repulsive Layout Engine: Adjust label font size (12–72 pt), minimum/maximum label offset distance (e.g., 40–80 px), and Repulsive force weight (default 100). The layout engine dynamically repositions peak labels to prevent overlaps.

Interactive Peak Table & Search

  • Search Peaks: Search peak assignments or chemical shift coordinates in the peak table via Search in peaks.
  • Jump to Peak: Click any peak row in the table to automatically center and zoom the 2D plot onto that peak.

Processing Raw 2D & Pseudo-3D Time-Domain Data (Bruker & NUS)

Processing Raw 2D & Pseudo-3D Time-Domain Data

COLMARvista features an integrated WebAssembly processing pipeline for raw Bruker 2D and Pseudo-3D time-domain FID data directly in the web browser, with full support for Non-Uniform Sampling (NUS).

Supported Experiments & Required Files

  • Supported Experiments: 2D and Pseudo-3D experiments from Bruker TopSpin console versions ≥ 3.0. Indirect dimension mode supports Echo-antiecho or States-TPPI.
  • Required Files:
    • Direct dimension time-domain fid (or ser) and acquisition file acqus.
    • Indirect dimension acquisition file acqu2s.
    • Indirect dimension 2 acquisition file acqu3s (required for Pseudo-3D experiments).
    • NUS Experiments: Upload the NUS schedule file nuslist for Non-Uniform Sampling experiments.
  • Drag & Drop Folder: Drag and drop the entire Bruker experiment directory containing all files.

Processing Parameters

  • Direct & Indirect Apodization: Customizable nmrPipe syntax apodization strings (e.g., SP off 0.5 end 0.98 pow 2 elb 0 c 0.5).
  • Zero Filling Factor: Select zero filling factors (2, 4, 8) independently for direct ($X$) and indirect ($Y$) dimensions.
  • Sub-Region Direct Extraction: Specify chemical shift bounds in Extract direct dimension from (ppm) to (ppm) to process a targeted sub-region and accelerate transformation.
  • Water Suppression: Check Water suppression? to attenuate solvent signals.
  • Negative Imaginary Data: Check Negative imaginary data to invert indirect dimension phase and correct inverted/flipped spectra.

Non-Uniform Sampling (NUS) Processing & Phase Estimation

COLMARvista provides specialized processing controls for 2D and Pseudo-3D Non-Uniform Sampling (NUS) experiments:

  • Automated Phase Correction for NUS (Direct Dimension Only): For NUS datasets, automated phase correction functions on the direct dimension only.
    How it works: To estimate direct dimension phase parameters ($P_0 / P_1$) on NUS data, the processing engine first executes a preliminary full direct Fourier Transform process (which contains NUS sampling artifacts) to calculate and optimize direct phase correction via ANN/entropy minimization. These phase parameters are then applied to the raw time-domain data before performing full 2D NUS reconstruction (SMILE / iterative reconstruction). Indirect dimension phase parameters cannot be automatically calculated on NUS data and must be set manually.
  • FLATT Baseline Correction for NUS: Check Direct dimension FLATT baseline correction for NUS to eliminate baseline distortion during NUS reconstruction.
  • Process NUS as Normal: Check Process NUS spectrum as normal (No NUS recon) to bypass NUS reconstruction and perform rapid direct FT processing.

Pseudo-3D Processing Options

  • Process First Plane Only: Rapid processing on plane 1 for parameter tuning.
  • Process All Planes: Sequential batch processing across all planes in a Pseudo-3D dataset.

Process & Reprocess Workflow

  • Click Upload experimental files and process to start Fourier Transformation.
  • Reprocessing: Select a spectrum from the list and click Reprocess to reload parameters into the form, adjust phase/apodization settings, re-run processing, and click Quit reprocessing when done.

Automatic & Manual Phase Correction for 2D Spectra

2D Phase Correction Workflow

Automatic Phase Correction

Click Automatic PC to run entropy-minimization or neural network automated phase correction on the active 2D spectrum.

Interactive Manual Phase Correction

Manual phase correction requires imaginary data to be retained during initial 2D FID processing.

  1. Select Spectrum: Select the target spectrum in Your spectra list and click Reprocess.
  2. Display 1D Cross Section: Switch to Cross section mode. Hover the cursor over a strong peak for 3 seconds or right-click to display horizontal ($X$) and vertical ($Y$) 1D cross section slices.
  3. Adjust Zero-Order Phase (P0): Move the cursor onto either the direct ($X$) or indirect ($Y$) 1D cross-section plot. Hold Shift (1.0° coarse adjustment) or Ctrl (0.2° fine adjustment) and scroll the mouse wheel.
  4. Set Anchor Point & Adjust P1: Click on a peak in the cross-section plot to set an anchor point (indicated by an anchor line). Hold Shift or Ctrl and scroll the mouse wheel to adjust first-order phase ($P_1$). Right-click to unset the anchor point.
  5. Apply Phase Correction: Click Apply PC to apply phase correction to the full 2D spectrum. The exact $P_0$ and $P_1$ values are updated in the processing form and displayed for export into nmrPipe scripts.

Pseudo-3D Series Processing & 2D DOSY Diffusion Workflow

Pseudo-3D Series Processing & 2D DOSY Workflow

Pseudo-3D experiments consist of a sequence of 2D NMR planes recorded under varying experimental conditions, such as relaxation delays ($T_1, T_2, T_{1\rho}$), titration concentrations, kinetics time points, pulsed field gradient strengths (DOSY), or saturation frequency offsets (CEST). COLMARvista provides an integrated pipeline to process raw time-domain datasets, deconvolve and fit peaks across all planes sequentially, and extract physical observables.

1. Loading or Processing Pseudo-3D Data

You can supply Pseudo-3D datasets in either raw time-domain or pre-processed frequency-domain format:

  • Raw Bruker Time-Domain Processing: Drag and drop the Bruker experiment folder containing ser (or fid), acqus, acqu2s, and acqu3s (plus nuslist if Non-Uniform Sampling was employed). Under Pseudo-3D processing options, select Process all planes and click Upload experimental files and process. The WebAssembly processing pipeline transforms each plane into frequency space with consistent phase and apodization.
  • Pre-processed Spectral Planes: Drag and drop or upload a series of processed 2D planes (NMRPipe .ft2, Sparky .ucsf, or ASCII .txt) into the Frequency domain spectra area. All planes will be indexed into Your spectra list.

2. Master Peak Picking & Initial Deconvolution (Plane 1)

To ensure consistent peak identities across planes, pseudo-3D fitting relies on a high-quality master peak list established on reference Plane 1 (typically the first spectrum or maximum intensity plane):

  1. Select Plane 1 in Your spectra list.
  2. Pick peaks using DEEP Picker (deep neural network deconvolution) or Simple Picker (local maxima), or upload an existing peak list (.list).
  3. Perform initial line-shape fitting by choosing Voigt or Gaussian and clicking Peak Fitting. This sets accurate starting coordinates, line widths, and initial amplitudes for every peak.

3. Multi-Plane Sequential Pseudo-3D Fitting

  1. Open the Pseudo-3D fitting tool panel.
  2. Set the Max round of pseudo-3D fitting (1–1000 iterations, default 50).
  3. Click Run Gaussian pseudo-3D fitting of all spectra or Run Voigt pseudo-3D fitting of all spectra.
  4. Fitting Mechanism: The algorithm uses the master peak list from Plane 1 as an initial guess. For each subsequent plane, it optimizes peak intensities, volumes, and positions while accounting for slight peak drifting across the series.
  5. Visual Inspection: Check Show pseudo-3D fitting result to overlay fitted peak markers on the active 2D plane. Select different planes from Your spectra list to verify peak tracking and fitting fidelity.
  6. Download Results: Click Download pseudo-3D fitted peaks to save a comprehensive peak table (.tab) containing peak frequencies, line widths, and fitted amplitudes across every plane.
  7. Reload Saved Pseudo-3D Peaks: Use Upload pseudo-3D fitted peaks (.tab) to restore previously fitted pseudo-3D peak tables without refitting.

4. 2D DOSY Diffusion Analysis

For pulsed field gradient diffusion experiments (DOSY), COLMARvista extracts diffusion constants ($D$) directly from pseudo-3D fitted peak intensities:

  1. Expand the DOSY fitting tool sub-panel.
  2. Input Gradient Strengths: Enter space-separated gradient values (in G/cm or normalized units) into DOSY gradient values (e.g., 0.963 8.474 15.986 23.497 31.009 38.520).
  3. Set Gradient Weights: Specify fitting weights (e.g., 1 0 0 1 1) to emphasize or de-emphasize specific gradient planes.
  4. Adjust Rescale Factor: Modify the Rescale factor (default 1000.0) to scale physical diffusion units appropriately.
  5. Run DOSY Fitting: Click Run DOSY fitting. The engine fits each peak's intensity decay to the Stejskal-Tanner relation:
    I(G) = I₀ × exp(-γ² G² δ² (Δ - δ/3) D)
  6. Interactive Decay Curves & Color-Coding: Fitted diffusion constants ($D$) automatically populate the peak table and color-code peak markers on the 2D plot. Hovering over any peak displays its exponential diffusion decay curve and fit quality in an interactive pop-up window.

Chemical Exchange Saturation Transfer (CEST) & ChemEx Workflow

Chemical Exchange Saturation Transfer (CEST) & ChemEx Workflow

Chemical Exchange Saturation Transfer (CEST) NMR is a powerful technique for probing slow-to-intermediate microsecond-to-millisecond ($k_{\text{ex}} \approx 10\text{--}1000\text{ s}^{-1}$) conformational exchange between a major, visible ground state ($A$) and sparsely populated, invisible "dark" excited states ($B$). In COLMARvista, CEST profiles ($I/I_0$ vs. saturation offset $\Omega_{\text{RF}}$) are analyzed using both automated multi-peak Voigt deconvolution and real-time numerical Bloch-McConnell simulation and fitting powered by ChemEx running directly in the browser via Pyodide WebAssembly.

1. Setting Up CEST Experimental Parameters

Expand the CEST fitting tool sub-panel and configure your acquisition parameters:

  • CEST Saturation Offsets (Hz): Enter space-separated saturation offsets in Hz (e.g., -2000 -1500 -1000 -500 0 500 1000 1500 2000), or click Upload offset file to load an offset list (.txt, .list, .tab, .dat, or .csv).
  • B1 Field Strength (Hz): Enter the continuous-wave or shaped weak irradiation field strength $B_1$ in Hz (e.g., 25 Hz).
  • CEST Relaxation Delay time_t1 (s): Enter the duration of the saturation period $T_1$ in seconds (e.g., 1.0 s).
  • B1 Inhomogeneity Bypass: Check b1_inh_scale = inf (disable B1 dephasing) if assuming an ideal homogeneous $B_1$ field or to accelerate simulation during initial exploratory analysis.

2. Automated Pre-Analysis & Multi-Peak Filtering

  1. Run Pre-Analysis: Click Pre-analysis. COLMARvista fits empirical multi-peak Voigt line-shapes to all extracted residue profiles. This rapidly locates major dips (ϖA) and identifies secondary dips (ϖB) indicative of chemical exchange.
  2. Filter Exchange-Active Residues: Click Show ≥2 Peaks Only in the CEST panel or the peak table header. The peak table and 2D spectrum will immediately filter to show only residues with two or more detected dips, filtering out inactive single-dip peaks and highlighting exchange-active sites.

3. Interactive Floating CEST Profile Viewer & Autozoom

Click on any peak in the peak table or click a peak circle on the 2D plot to open the floating Pseudo-3D Peak Profile window:

  • Automatic Autozoom to Dips: When opening a CEST profile, COLMARvista automatically scans the profile for negative dips. If one or two dips are present, the viewer automatically zooms into the dip region, bypassing broad flat baseline regions so you can immediately inspect the exchange feature. (Autozoom is skipped if no distinct dip is detected).
  • Zoom Button (Zoom): Click to manually re-trigger autozoom onto the resonance dips at any time.
  • Reset View (↺): Click the reset button in the window header to restore the full unzoomed profile view across all saturation offsets.
  • Voigt Fit Overlay (Voigt: ON/OFF): Toggles display of the empirical pre-analysis Voigt deconvolution curve.
  • ChemEx Fit Overlay (ChemEx: ON/OFF): Toggles display of the numerical Bloch-McConnell ChemEx fit curve.
  • Resize & Drag: Drag the window header to reposition, or drag any border/corner to resize the plot.

4. Real-Time ChemEx Simulation & Interactive Side Panel

Click the purple ⚙ Sim & Fit button in the profile window header to slide open the interactive ChemEx parameter panel:

  • Client-Side Execution: Powered by Pyodide WebAssembly running the Python ChemEx package entirely inside a browser WebWorker. No server upload or local Python installation required!
  • Interactive Parameter Sliders & Number Boxes:
    • pB (Minor Pop): Population of the excited state (slider 0.001–0.150, number input 0.0001–0.49).
    • kex (Rate, s⁻¹): Total exchange rate constant $k_{\text{ex}} = k_{AB} + k_{BA}$ (slider 5–500, number input 1–5000).
    • ϖA (Major CS, ppm): Chemical shift of the ground state $A$.
    • ΔϖAB (B - A, ppm): Chemical shift difference ϖB - ϖA between excited state $B$ and ground state $A$ (slider -15 to +15, number input -25 to +25).
  • Instant Live Curve Simulation: Adjusting any slider or number box immediately recalculates the Bloch-McConnell matrix simulation curve in real time, allowing you to manually align the simulation with experimental data points.
  • ⚡ Fit This Peak Only: Click to run a fast, isolated Levenberg-Marquardt fit for the active peak. ChemEx numerically converges $k_{\text{ex}}$, $p_B$, ϖA, and ΔϖAB for that individual residue within seconds and updates the profile display and initial guess.
  • 🔄 Reset Initial Guess: Restores default or pre-analysis initial values.

5. Global ChemEx Batch Fitting & Results Export

  1. Generate ChemEx Input: Click Gen Chemex input to generate the complete experiment definition files (including experiment.toml, parameters, and experimental intensity profiles).
  2. Save Input: Click Save input to download a .zip bundle of the generated ChemEx project directory (ideal for running on high-performance computing clusters).
  3. Run ChemEx: Click Run Chemex to execute simultaneous global multi-peak fitting across all peaks directly inside the browser. Progress is displayed in real time in the status area.
  4. Download Results: Once fitting completes, click Download CEST results to export fitted kinetic rates ($k_{\text{ex}}$, $p_B$), chemical shifts, error bars, and normalized profiles.

Automated Assignment Transfer Tool (Hungarian Algorithm)

Automated Assignment Transfer Tool

The Assignment transfer tool allows you to rapidly transfer resonance assignments (such as backbone sequence assignments, e.g. A154N-HN, V157N-HN) from a reference assignment file to your active 2D peak list or Pseudo-3D series peaks using the globally optimal Hungarian matching algorithm.

1. Supported File Formats & Column Parsing

Click Load assignment file and select your reference assignment list. COLMARvista supports:

  • Sparky Peak Lists (.list): Standard Sparky formatted lists containing Assignment, w1 (indirect/heteronucleus chemical shift in ppm), and w2 (direct/$^1$H chemical shift in ppm).
  • NMRPipe Tables (.tab): Formatted tables with ASS, X_PPM, and Y_PPM columns.
  • Tabular Plain Text (.txt, .dat, .csv): Any whitespace- or comma-delimited table with a header line specifying Assignment, w1, and w2.

2. Globally Optimal Hungarian Matching Algorithm

Traditional nearest-neighbor assignment can fail in congested regions where multiple experimental peaks compete for the same reference assignment. COLMARvista implements the exact Hungarian algorithm (Kuhn-Munkres, $O(N^3)$ via HuangarianInt32.js):

  • A cost matrix is constructed using normalized chemical shift distances:
    Distance = √[ (Δω¹H / Cutoff¹H)² + (Δωhetero / Cutoffhetero)² ]
  • The algorithm globally minimizes total distance across all assignments simultaneously, ensuring a mathematically optimal, conflict-free 1-to-1 matching.
  • Pairs exceeding user-defined distance cutoffs are assigned high dummy penalty costs and rejected as unmatched.

3. Distance Cutoffs & Global Chemical Shift Calibration

Located in the assignment transfer panel:

  • ¹H Cutoff (ppm): Maximum allowable chemical shift deviation in the direct dimension (default: 0.02 ppm, or customized).
  • Heteronucleus Cutoff (ppm): Maximum allowable chemical shift deviation in the indirect dimension (default: 0.20 ppm, or customized).
  • Global ¹H Shift (ppm): Calibration offset added to all incoming reference $^1$H coordinates (ω¹H, calib = ω¹H, ref + Δ¹H) prior to matching.
  • Global Hetero Shift (ppm): Calibration offset added to all incoming reference heteronucleus coordinates (ωhetero, calib = ωhetero, ref + Δhetero) prior to matching.
  • Correcting Referencing Offsets: When transferring assignments between spectra acquired on different spectrometers, temperatures, or referencing standards (e.g. DSS vs. TSP), adjust the global shifts to align the reference overlay directly over the experimental peaks.

4. Interactive Re-Run & Clear Unmatched Option

  • Instant Re-Run (Enter or Re-run Button): You do not need to re-upload your file to test different cutoffs or shifts. Simply modify any cutoff or shift input and press Enter or click Re-run transfer. Matching recalculates and updates the 2D visual overlay in milliseconds.
  • Clear Unmatched Checkbox: Check Clear unmatched peak assignments before running transfer if you want experimental peaks that fall outside the cutoff to have their existing assignment text cleared.

5. Real-Time 2D Visual Overlay & Verification

Upon transferring assignments, COLMARvista displays a dynamic graphical overlay directly on the 2D contour plot:

  • Diamonds (◊): All incoming reference assignments are plotted as diamond markers:
    • Solid Blue Diamond: Successfully matched to an experimental peak within cutoffs.
    • Dashed Amber Diamond: Unmatched reference entry (exceeds cutoffs or no corresponding peak).
  • Directed Match Arrows: A solid blue arrow points from each reference diamond directly to the center of its matched experimental peak circle, providing unambiguous visual confirmation of which peak received each assignment.
  • Interactive Tooltips: Hover the cursor over any diamond to view a tooltip showing the assignment label, incoming/calibrated coordinates, and the matched peak's experimental coordinates.
  • Dynamic Zoom & Pan Sync: All diamonds and arrows remain locked to their exact chemical shift coordinates and smoothly reposition during zooming and panning.

6. Finalizing Assignments

  1. Inspect the 2D overlay and the peak table to ensure satisfactory matching.
  2. Click the prominent green Finalize transfer button.
  3. The preview diamonds and arrows are immediately cleared from the 2D plot.
  4. All transferred assignment labels are permanently applied to your active peak list and table, ready for label repositioning, peak profile inspection, or workspace session saving (.save).
